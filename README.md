# Praktikum Pemrograman Berbasis Objek (PBO)

Repository ini berisi kumpulan tugas, modul, dan latihan praktikum Pemrograman Berbasis Objek (PBO) menggunakan bahasa pemrograman Java.

---

## 📌 Deskripsi Program / Modul

Berikut adalah daftar file dan penjelasan singkat mengenai program yang ada di dalam repository ini:

### 1. `Produk.java`
- **Fungsi**: Merupakan *class model* yang merepresentasikan data produk/barang.
- **Fitur/Properti**:
  - Menyimpan atribut produk seperti `kodeProduk`, `namaProduk`, `harga`, dan `stok`.
  - Mengatur konstanta pajak (`PAJAK`).
  - Menyediakan *constructor* untuk inisialisasi objek produk.
  - Memiliki *method* untuk menghitung subtotal dan pajak dari produk.

### 2. `SistemKasir.java`
- **Fungsi**: Merupakan *class* utama/sistem yang mengelola transaksi penjualan kasir.
- **Fitur/Properti**:
  - Mengolah transaksi pembelian barang.
  - Menghitung total harga, diskon, pajak, dan kembalian pembayaran.

### 3. `Student.java` & `Main.java`
- **Fungsi**: Kelas latihan dasar PBO mengenai penerapan class, object, encapsulation, serta testing executable program.
